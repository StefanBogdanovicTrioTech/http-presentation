Dve vrste HTTP poruka

Request vs. Response

Zahtev i odgovor imaju sličnu strukturu, ali njihove početne linije i namene se razlikuju.

HTTP Request

Poruka koju klijent šalje serveru kako bi zatražio resurs ili izvršenje određene operacije.

01
Request Line — metoda, cilj zahteva i verzija.
02
Headers — dodatne informacije o zahtevu.
03
Body — opcioni podaci koje klijent šalje.

HTTP Response

Poruka kojom server obaveštava klijenta o ishodu obrade zahteva i po potrebi vraća sadržaj.

01
Status Line — verzija, statusni kod i opis.
02
Headers — metapodaci o odgovoru.
03
Body — opcioni sadržaj koji server vraća.
Tehnički detalj

Čemu služi prazan red?

U HTTP/1.1 porukama zaglavlja se završavaju praznim redom, odnosno sekvencom CRLF CRLF. Na taj način razdvajaju se zaglavlja od eventualnog tela poruke.

Ako telo postoji, ono počinje nakon tog razdvajanja. Pravila za određivanje dužine tela zavise od konkretne poruke i njenih zaglavlja.

HTTP/1.1 200 OK Content-Type: text/plain Content-Length: 5 ↳ CRLF — prazan red Hello

Zapamti

HTTP poruka ima jasnu strukturu.

Početna linija govori šta se traži ili kakav je rezultat zahteva. Zaglavlja pružaju dodatne informacije, a telo poruke prenosi sadržaj kada postoji. Razumevanje ove strukture pomaže nam da analiziramo komunikaciju između browsera i servera.
