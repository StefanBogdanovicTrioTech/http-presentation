JavaScript Fetch API

Zašto koristimo fetch()?

Fetch API omogućava JavaScript kodu da šalje HTTP zahteve i asinhrono obrađuje odgovore.

GET

Slanje zahteva

Funkcija fetch() započinje zahtev prema zadatoj adresi. Podrazumevana HTTP metoda je GET.

await

Asinhrona obrada

JavaScript može da čeka rezultat asinhrone operacije pomoću async/await sintakse bez blokiranja glavne niti tokom mrežnog čekanja.

JSON

Rad sa podacima

JSON je čest format razmene podataka između web aplikacija i servera. JavaScript može da ga pretvori u objekte i nizove.

Šta ako se pojavi 404 ili Network error?

Ako dobiješ 404 Not Found, browser je možda uspešno kontaktirao server, ali fajl data/example.json još ne postoji na traženoj adresi.

Ako stranicu otvoriš direktno preko file://, browser može blokirati fetch zahtev zbog bezbednosnih ograničenja. Zato projekat pokreći pomoću VS Code Live Servera ili preko GitHub Pages.

Važno je i da fetch() ne odbacuje Promise samo zato što je server vratio status poput 404 ili 500. Za proveru uspešnog HTTP odgovora koristimo response.ok ili response.status.

Zapamti

HTTP nije samo teorija. Koristimo ga svakodnevno.

Uz Fetch API možemo da šaljemo HTTP zahteve iz JavaScripta, dobijamo odgovore servera i obrađujemo podatke bez ponovnog učitavanja cele web stranice. Developer Tools nam omogućava da detaljno ispitamo te zahteve i razumemo šta se događa na mreži.
