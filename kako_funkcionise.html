Razumevanje procesa

Tri ključne faze HTTP komunikacije.

Bez obzira na to koji sajt otvaramo, osnovna ideja HTTP protokola ostaje ista.

01

Klijent šalje zahtev

Browser navodi šta želi da dobije ili uradi. Zahtev sadrži HTTP metodu, ciljnu putanju i odgovarajuća zaglavlja.

02

Server obrađuje zahtev

Server pronalazi traženi resurs ili izvršava potrebnu operaciju. Zatim priprema HTTP odgovor.

03

Klijent prima odgovor

Browser dobija statusni kod, zaglavlja i eventualno telo odgovora. Ako je sadržaj HTML, može ga prikazati kao web stranicu.

HTTP u stvarnom svetu

Možeš videti svaki HTTP zahtev.

Web browseri imaju ugrađene Developer Tools koji nam omogućavaju da pregledamo mrežnu komunikaciju.

Otvori Developer Tools pomoću tastera F12, izaberi karticu Network i osveži stranicu.

Tu možeš da vidiš URL, metodu, statusni kod, vreme zahteva, zaglavlja i podatke odgovora.

F12 → Network → Reload

Zapamti

HTTP se zasniva na zahtevu i odgovoru.

Klijent inicira HTTP zahtev, a server vraća odgovor. Jedno učitavanje web stranice često uključuje više HTTP zahteva, jer browser posebno preuzima HTML, CSS, JavaScript i druge resurse.
