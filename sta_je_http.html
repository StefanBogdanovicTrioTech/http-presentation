Definicija

Šta je zapravo HTTP?

HTTP (Hypertext Transfer Protocol) je protokol aplikacionog sloja namenjen razmeni informacija na webu. Zasniva se na modelu zahtev–odgovor (Request–Response): klijent šalje zahtev, a server vraća odgovor koji sadrži rezultat obrade i, po potrebi, tražene podatke. HTTP se koristi za prenos HTML dokumenata, slika, video sadržaja, JSON podataka i mnogih drugih resursa.

Tri važna pojma

HTTP, HTML i Browser nisu isto.

Ova tri pojma često se koriste zajedno, ali imaju potpuno različite uloge.

Šema / protokol

https označava da se koristi HTTP komunikacija zaštićena TLS-om.

Zanimljivost: HTTP je stateless protokol.

To znači da svaki HTTP zahtev može samostalno da se obradi i da protokol ne zahteva pamćenje prethodnih zahteva. Sajtovi ipak mogu da održavaju korisničke sesije pomoću kolačića (cookies) i drugih mehanizama.
