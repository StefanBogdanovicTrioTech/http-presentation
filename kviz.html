HTTP komunikacija

Browser šalje zahtev, a server vraća odgovor. HTTP određuje strukturu i značenje te razmene.

200

Metode i statusi

HTTP metode opisuju tražene operacije, a statusni kodovi pokazuju rezultat njihove obrade.

TLS

Bezbednost i razvoj

HTTPS štiti HTTP komunikaciju pomoću TLS-a, dok novije verzije HTTP-a poboljšavaju efikasnost prenosa.

Kraj prezentacije

Iza svake web stranice stoji komunikacija.

Svaki put kada otvoriš sajt, preuzmeš sliku, pošalješ formular ili koristiš web aplikaciju, HTTP omogućava razmenu informacija između klijenta i servera. Razumevanje HTTP-a jedan je od važnih koraka ka razumevanju web programiranja.
