HTTP/1.1 — bez multiplexinga

HTTP/1.1 podržava trajne TCP veze, ali ne omogućava multiplexing kao HTTP/2. Browser može koristiti više TCP veza za paralelne zahteve.

Osnovni princip

Tehnologija se menja. Ideja ostaje ista.

Najvažnija HTTP pravila zadržavaju svoje značenje kroz savremene verzije.

GET

HTTP metode

Metode kao što su GET, POST i DELETE zadržavaju svoju osnovnu namenu. Menja se način njihovog prenosa, a ne samo značenje.

200

Statusni kodovi

Kodovi poput 200 OK i 404 Not Found imaju isto osnovno značenje u HTTP/1.1, HTTP/2 i HTTP/3.

⇄

Zahtev i odgovor

Klijent i dalje šalje zahtev, a server vraća odgovor. Taj model ostaje osnova web komunikacije.

Zapamti

HTTP evoluira. Web napreduje.

HTTP/1.1 omogućio je efikasnije korišćenje trajnih TCP veza. HTTP/2 doneo je binarno uokviravanje, multiplexing i kompresiju zaglavlja. HTTP/3 koristi QUIC kako bi unapredio način prenosa podataka i smanjio probleme povezane sa blokiranjem tokova pri gubitku paketa.
