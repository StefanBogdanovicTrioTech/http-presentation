Uporedi metode

Koja metoda šta radi?

Poređenje najvažnijih HTTP metoda i njihovih osnovnih svojstava.

Metoda Namena Safe Idempotent
GET Preuzimanje resursa DA DA
POST Obrada poslatih podataka NE NE*
PUT Kreiranje ili zamena resursa NE DA
PATCH Delimična izmena resursa NE NE*
DELETE Uklanjanje resursa NE DA
Šta znače Safe i Idempotent?

Safe znači da metoda ne zahteva promenu stanja servera kao svoju nameravanu operaciju. Na primer, GET služi za čitanje podataka.

Idempotent znači da ponavljanje identičnog zahteva ima isti nameravani efekat na stanje servera kao jedno izvršavanje. To ne znači da odgovor mora biti identičan svaki put.

* POST i PATCH nisu podrazumevano idempotentni, ali konkretna API operacija može biti projektovana da se ponaša idempotentno.

Primena u programiranju

HTTP metode u web aplikacijama.

Primeri tipičnih REST API operacija nad resursom korisnika.

GET

Pregled korisnika

Aplikacija preuzima informacije o korisniku kako bi ih prikazala.

POST

Registracija korisnika

PUT /api/users/1

Promena imena

Menja se samo određeni deo podataka, bez zamene celog resursa.

DELETE /api/users/1

Zapamti

HTTP metoda opisuje željenu operaciju.

GET preuzima podatke, POST ih prosleđuje na obradu, PUT kreira ili zamenjuje resurs, PATCH ga delimično menja, a DELETE zahteva njegovo uklanjanje. Metoda je važan deo HTTP zahteva, ali tačan rezultat zavisi od implementacije servera.
