06 / 10 — HTTP odgovori

Svaki odgovor ima svoj kod.

Kada server primi HTTP zahtev, vraća odgovor sa troznamenkastim statusnim kodom. Taj kod govori klijentu da li je zahtev uspešan, da li je potrebno preusmeravanje ili je došlo do problema.

Klasifikacija

Pet grupa HTTP statusa.

Prva cifra statusnog koda određuje kojoj grupi pripada odgovor.

1xx

Informacije

Privremeni odgovor. Obrada zahteva se nastavlja.

2xx

Uspeh

Zahtev je uspešno primljen i obrađen.

3xx

Preusmeravanje

Potrebno je dodatno postupanje, poput korišćenja druge adrese ili keša.

4xx

Greška klijenta

Problem sa zahtevom ili pristupom resursu.

5xx

Greška servera

Server nije uspeo da ispuni zahtev.

Najpoznatiji odgovori

Statusni kodovi koje najčešće srećemo.

Ovi kodovi predstavljaju neke od najprepoznatljivijih HTTP odgovora.

200

OK

Uspešno preuzimanje stranice, slike ili JSON podataka.

301

Moved Permanently

Server javlja da je resurs trajno premešten na novu adresu.

404

Not Found

Tražena stranica ili drugi resurs nije pronađen.

500

Internal Server Error

Neočekivana greška na serveru sprečila je obradu zahteva.

403

Forbidden

Server razume zahtev, ali odbija da omogući pristup.

503

Service Unavailable

Server trenutno ne može da obradi zahtev, na primer tokom održavanja.

Zapamti

Prva cifra otkriva vrstu odgovora.

Statusni kodovi omogućavaju klijentima da razumeju rezultat HTTP zahteva. Pored uspešnih odgovora, postoje informativni odgovori, preusmeravanja, greške povezane sa zahtevom i greške na strani servera.

1xx — Info 2xx — Success 3xx — Redirect 4xx — Client Error 5xx — Server Error
